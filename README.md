# Stormy Communication Jos

A modern and responsive demo e-commerce website created for **Stormy Communication Jos**, a mobile phone and gadget store located in Jos, Plateau State, Nigeria.

The website is designed to give customers an easy way to browse available phones, gadgets and accessories, view prices, and contact the store directly to place an order.

## Features

- Responsive design for phones, tablets and computers
- Product catalogue with prices
- Product categories
- Product search
- Direct WhatsApp ordering
- Click-to-call functionality
- Store information and location
- Mobile navigation menu
- Smooth scrolling and subtle animations
- Clean custom-designed interface
- Easy to update and expand

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts

## Ordering

Customers can browse products on the website and use the WhatsApp order buttons to contact Stormy Communication directly about availability, pricing and orders.

## Future Admin Dashboard

The website can be expanded with a secure admin dashboard that allows the business owner to:

- Add new products
- Upload product images
- Set product prices
- Edit existing products
- Delete products
- Update product availability

A database/backend service can be connected so changes made from the admin dashboard automatically appear on the main website.

## Purpose

This project is currently a **website demonstration** showing how an online storefront for Stormy Communication could look and function.

Business information used in the demo should be reviewed and approved by the business owner before the website is published as an official website.
